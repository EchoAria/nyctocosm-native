# 迁移状态与验收边界

更新时间：2026-09-22。版本：0.3.0-native-alpha.11。

## 实现路线

原始函数仅作为设计规格及美术帧数据来源。运行时不包含 `.mcfunction`，不依赖 load/tick 函数标签，不创建玩法记分板，不召唤标记/盔甲架组合体来代替原生生物。

| 原包机制 | 原生实现 |
| --- | --- |
| 原版物品 + CustomModelData | 注册 Item / SwordItem / BlockItem 与创造标签 |
| 命令伤害与实体类型白名单 | LivingEntity.hurt、DamageType、Forge 伤害事件 |
| 世界共享 Boss 分数 | 每个 NativeBoss 的生命、同步字段、阶段与动作状态 |
| Animated Java 显示实体骨架 | 原几何模型 + 转换后动画矩阵，由客户端实体渲染器绘制 |
| 灵场 marker 与掉落物扫描 | 带所有者的 SeelicField 实体、原生材料匹配 |
| 法术 marker 位移 | SpellBolt 碰撞投射物、SpellArea 持续区域 |
| 祭坛村民交易 | DaisBlock / DaisMenu / DaisScreen，服务器扣料 |
| 传送门展示实体与坐标命令 | 原生 Portal Block、边框验证与安全传送 |
| 剧情记分板替换书 | ItemStack 章节数据、玩家进度 NBT、单向打开书界面消息 |

原生模组也正常使用 Minecraft 的数据驱动资源格式（维度、世界生成、战利品、配方、标签）。这些 JSON 不是旧数据包玩法解释器。

## 仍未达到原版体验的主要部分

1. **Boss 战斗**：Sorcerer 的六阶段、Nullpoint 与 12 种攻击，以及 Serpent 的三套攻击链、分段受击和死亡演出已改为原生状态机。Emissary 的所有阶段机制、专属 VFX 和击败后的完整流程仍需继续实现。
2. **法术系统**：17 种已建立可运行行为，但完整六元素属性、加成、弱点、超迹概率和耗散公式尚未等价迁移。Submergence 目前不是原触手实现；反射、反制、引力等也存在几何/时序差异。
3. **生存流程**：普通怪物自然生成、Tony/NPC、全部获取途径、世界事件、任务解锁和结束流程未完成。刷怪蛋、测试指令不能替代这些内容。
4. **美术**：导入 10 套骨架、5607 个动画帧记录不等于所有动画都已正确接入。已修正 Boss 根朝向和每个骨骼物品局部 180° 旋转的先后顺序，并修正 Emissary 第二阶段过渡长度；部分攻击 VFX、传送门完整画面和仪式演出仍待完善。发光模型与原 Boss 分段音乐已接入，但未与运行原数据包的同一场景逐帧、逐拍对照。
5. **普通怪物**：Death Walker / Apparition 的血量、碰撞体、移动/生成行为仍是近似值。原 Death Walker 借用 giant 受击载体，不能直接认为当前原生尺寸已还原。
6. **战利品**：Sorcerer 与 Serpent 的原掉落轮数、数量及经验值已恢复；Emissary 和普通生物掉落仍需逐项核对。共享模型的书籍战利品及原版战利品覆盖也未全部迁移。
7. **界面与语言**：祭坛使用常规合成界面，不是原交易/仪式动画。37 种注册物品和全部剧情书内容已有中英双语，但原包遗留的部分字幕、世界文本与未来补入内容仍需继续核对。
8. **互通**：无旧存档迁移、无第三方模组集成测试、无多人长时间实测。遵守 Forge 伤害事件，不强行绕过其他模组的无敌或取消事件。
